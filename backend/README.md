## Overview

The Education Management Information System (EMIS) is a modern, scalable solution designed to streamline educational institution operations. Built on Laravel's robust framework with a RESTful API architecture, the system provides comprehensive tools for managing students, teachers, courses, grades, attendance, and administrative functions.

## Features
### Student Management

Student registration and profile management
Academic history tracking
Enrollment management
Parent/guardian information

### Teacher Management

Teacher profiles and credentials
Course assignments
Schedule management
Performance tracking

### Course Management

Course catalog administration
Class scheduling
Curriculum management
Subject organization

### Grades & Assessment

Grade book management
Assignment tracking
Exam scheduling
Progress reports
GPA calculation

### Attendance System

Daily attendance tracking
Automated notifications
Attendance reports
Leave management

### User Management

Role-based access control (RBAC)
Multi-level authentication
User permissions
Activity logging

### Reports & Analytics

Student performance reports
Attendance statistics
Financial reports
Custom report generation

## Technology Stack

Backend Framework: Laravel 10.x
API Architecture: RESTful API
Database: MySQL 8.0
Containerization: Docker & Docker Compose
Web Server: Nginx
PHP Version: 8.2
Cache: Redis
Queue: Redis Queue
Authentication: Laravel Sanctum / JWT
Testing: PHPUnit, Pest

💻 System Requirements

Docker Desktop 4.0+ (for Docker setup)
OR
PHP 8.2 or higher
Composer 2.x
MySQL 8.0 or higher
Redis (optional, for caching)
Node.js 18+ & NPM (for frontend assets)
